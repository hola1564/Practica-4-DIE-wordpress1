Introducción a Docker Compose

Aprende a gestionar contenedores de forma sencilla

¿Qué es Docker Compose?

Docker Compose es una herramienta que permite crear y gestionar varios contenedores utilizando un único archivo de configuración. Así podemos iniciar una aplicación completa con un solo comando.

¿Cómo funciona?

Para utilizar Docker Compose, creamos un archivo llamado docker-compose.yml, donde indicamos los servicios, las imágenes y los puertos que necesitamos.

Ejemplo de configuración

services:
  web:
    image: nginx
    ports:
      - "8080:80"

Comandos básicos

Estos son los comandos más utilizados:

docker compose up -d
docker compose ps
docker compose logs
docker compose down

Con estos comandos podemos iniciar los contenedores, comprobar su estado, ver los registros y detenerlos.

Ventajas de Docker Compose

  • Facilita la gestión de varios contenedores.
  • Permite reutilizar configuraciones.
  • Ahorra tiempo al iniciar aplicaciones.
  • Hace más sencillo organizar los servicios.
